# Changelog

## 0.4.1 — 2026-08-17

- **Ask for a review from the Source Control view.** A **Request Review** button
  in the Source Control title bar reviews everything you have changed, and each
  changed file in the list gets its own inline review action — no need to open the
  file first.
- **Review requests read properly in the terminal.** When Crit hands a request to
  a Claude Code session running in your terminal, it now arrives as a single
  formatted message instead of one long run-on line.
- Refreshed the extension icon and marketplace description.

## 0.4.0

- **Ask your agent for a review, not just replies to yours.** Crit can request a
  full review of your working changes — or of a single file — and the findings
  come back as inline comments in your editor, ready to reply to or resolve.
- **Works with Claude Code running in your terminal or panel.** Comments are
  delivered to the session you already have open, rather than starting a new
  conversation.
- **Several VS Code windows at once.** Comments and replies now always land in
  the window you sent them from.
- Renamed to **Crit**.

Earlier releases predate this changelog — see the version history in the README.
